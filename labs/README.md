# Lab thử nghiệm

Thư mục này chứa code thử nghiệm đang phát triển và chưa được đưa vào luồng ứng dụng. Lab renderer TikTok ở `tiktok/renderer/`.

Code sản phẩm nằm trong `apps/`; kiểm thử và hồ sơ nghiệm thu theo đợt ở `tests/`, raw bằng chứng ở `docs/evidence/`. Các lab cũ vẫn giữ nguyên vị trí để bảo toàn lịch sử. Khi tạo thử nghiệm mới, đặt implementation trong `labs/` và fixture trong `tests/`, ghi rõ phạm vi, guard và trạng thái nghiệm thu.
