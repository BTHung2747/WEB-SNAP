# Cobalt source and modifications

- 2026-10-30 optional-preview successor: pinned yt-dlp thumbnail metadata and Cobalt photo picker URLs feed bounded job-local JPEG previews through the existing Requests/egress transport. Public FFmpeg scaling/decoding and Python3.11 Process/Pipe APIs provide pixel normalization and an independently killable HTTP-only helper. A separate counted, opt-in preview capability cannot replace mandatory metadata proof. Only native exit0/group reap plus accepted optional proof publishes the cache; owner-only API reads never fetch source URLs. Photo preview normalization digests bind fresh prepared originals when a preview exists; structural v1 keys alone remain non-content identities. Source cookies/URLs remain RAM-only, primary video/image bytes remain unchanged, and the upstream resolver, license and dependency pins are unchanged. Offline fixtures do not enable or verify live previews.

- 2026-10-30 short-link successor: reuse Requests public Adapter.send and urllib.parse to resolve at most two HTTPS TikTok share redirects under the original analyze deadline. The official TikTokVMIE HEAD/autofollow route is deliberately not invoked. Server-derived short-analyze profile binds normalized URL hash/job/epoch, strict canonical bodyID/kind validation precedes DB binding; prepare uses canonical only. Desktop tracking/slash, vt/vm and /t/ normalize without storing tracking, cookies or redirect bodies. Existing canonical/photo/pair budgets, source extractor, dependencies, license and historical evidence remain intact; offline fixtures are not live short-link acceptance.

- 2026-10-30 companion successor: public v2 rendition fingerprints bind fresh bodyID/video/audio-donor/default descriptors. The existing Cobalt validator supplies a private RAM-only default URL digest to match formats after yt-dlp deduplication; no source URL/digest is persisted publicly. Only server-verified composite selections receive the bound v2 two-media/4-CONNECT profile. FFmpeg local stream-copy verifies native timelines, encoded packet hashes, full decode and owned cleanup. Native video is limited to orientation-normalized Full HD with honest default/highest markers; single/photo quotas, licenses and dependency pins remain. Offline fixtures are not source/production acceptance.

- 2026-10-30, WED SNAP source-quality integration: accept pinned yt-dlp PlayAddr HEVC/H265 progressive MP4 only when audio is declared; preserve H264 public identities/default order. Fresh prepare binds the actual FFprobe video/audio codecs, dimensions and durations before full decode/hash. Missing audio, changed selection or mismatched files fail with owned cleanup; no conversion, companion request, network-budget increase, extractor/vendor/dependency modification or default-policy change. Offline synthetic-media acceptance is not a real-source HEVC/audio or player-compatibility claim.
